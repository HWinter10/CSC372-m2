## Bank Balance GUI Application

This project is a simple graphical user interface (GUI) banking application developed in Java. The program allows a user to interact with a simulated bank account by depositing money, withdrawing money, and checking the current account balance through an interactive interface.

The application demonstrates foundational object-oriented programming concepts and basic GUI interaction using Java. It was developed as part of coursework to practice connecting user interface actions with underlying program logic.

### Features
- Deposit funds into an account
- Withdraw funds from an account
- Display the current account balance
- Simple user interface for interacting with account functions

### Technologies Used
- Java  
- Eclipse IDE  
- Basic GUI components (Java GUI libraries)
